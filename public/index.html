How to Use
1
Paste code
Select language, paste your code in the left panel, and click Display.
2
Select & annotate
Drag to select code text on the canvas. Click the Annotate button that appears.
3
Write descriptions
Type your explanation in the sidebar. Use the toolbar for bold, italic, lists, etc.
4
Customize
Change highlight color, text color, and font size per annotation. Drag cards and arrows freely.
5
Resize
Drag the corner grip on the code block, cards, or the export area border to resize.
6
Export
Click Export PNG to preview, then download your annotated code image.
Tips
  • Double-click an arrow endpoint to reset it to default position
  • Double-click the code/export resize grip to reset size
  • Click a card to bring it to front when overlapping
  • Toggle dark/light theme with the sun/moon button
